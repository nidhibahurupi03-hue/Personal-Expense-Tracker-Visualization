# 💰 Personal Expense Tracker with AI Dashboard

## 🚀 Project Overview
This is an AI-powered Personal Expense Tracker built using Python and Streamlit.  
It helps users track expenses, analyze spending patterns, and visualize financial data using interactive charts.

---

## 🎯 Problem Statement
People often lose track of daily expenses, leading to poor financial management.  
This project solves that by providing a smart dashboard to analyze spending habits.

---

## 🧠 Features
- ➕ Add expenses via UI
- 🗄️ SQLite database storage
- 📊 Category-wise analysis
- 📈 Monthly spending trends
- 💳 Payment method analysis
- 📅 Daily expense tracking
- 📉 Interactive visual dashboard (Plotly)
- ⚡ Real-time updates

---

## 🛠️ Tech Stack
- Python 🐍
- Streamlit 🎨
- Pandas 📊
- Plotly 📈
- SQLite 🗄️
